# .cd メタコマンド

## 概要
`.cd` は CLI で直接入力するドットメタコマンドで、Erq の子プロセス（クエリ実行プロセス）のカレントディレクトリを変更します。これにより、その後のファイル参照や `load table` などで与える相対パスの基準が更新されます。

## 構文
```text
.cd PATH
```

- `PATH`: 移動先ディレクトリ。スペースを含む場合は `'...'` もしくは `"..."` で囲みます。

## 挙動
- 引数が 1 つだけ指定された場合に `process.chdir(PATH)` を実行し、成功すると新しいカレントディレクトリが即座に適用されます。
- 引数数が不正なときは `usage: .cd PATH` を表示し、ディレクトリは変更されません。
- 指定したパスが存在しない場合などには Node.js が例外を送出し、エラーメッセージが表示されます（セッションは継続します）。
- 変更後は `load table` や `set output to file ...` など、ファイルパスを扱うステートメントで用いる相対パスの解決先が新しいディレクトリになります。
