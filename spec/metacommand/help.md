# .help メタコマンド

## 概要
`.help` は利用可能なドットメタコマンドの一覧や、個別コマンドの使い方を表示します。`.help` の実行結果は標準エラーに出力されます。

## 構文
```text
.help
.help COMMAND
```

- 引数なし: すべてのドットメタコマンドと簡単な説明を一覧表示します。
- `COMMAND`: 対象のドットメタコマンドの概要・使用例・補足情報を表示します。

## 挙動
- 未知のコマンド名を指定するとエラーメッセージを表示し、失敗として扱います。
- `.help debug` を指定すると、デバッグログで利用できるカテゴリの一覧も併せて表示されます。
- 自動補完 (`Tab`) は `.help` の後に利用可能なドットメタコマンド名を候補として提示します。
