# .load メタコマンド

## 概要
`.load` は CLI から直接実行できるドットメタコマンドで、SQLite 拡張モジュールを読み込み、現在の Erq セッションから追加の関数や集約を利用できるようにします。内部的には `better-sqlite3` の `loadExtension` を呼び出して拡張を現在のデータベース接続へ組み込みます。

## 構文
```text
.load PATH
```

- `PATH`: ロードする拡張モジュールのファイルパス。パスに空白が含まれる場合は `'...'` もしくは `"..."` で囲みます。

## 挙動
- 引数が 1 つのときにのみ実行され、成功すると以降のクエリで拡張が提供する関数を呼び出せるようになります。
- 引数が不足または過剰な場合は `usage: .load PATH` を標準エラーに表示し、処理は失敗として扱われます。
- 読み込み中に例外が発生した場合は例外メッセージ（`--debug` 起動時はスタックトレースを含む）が表示され、セッションは継続します。
- 拡張は現セッションのプロセス単位でロードされるため、一度成功すれば同じセッション内の後続クエリから追加定義を利用できます。
