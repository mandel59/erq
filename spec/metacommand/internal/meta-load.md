# 内部メタコマンド `meta-load`

`meta-load` はユーザーが記述する `load table ... from ...;;` 構文を子プロセス側で処理するための内部メタコマンドです。`.meta-load` のようなドットメタコマンドは存在せず、構文解析されたステートメントが `runCLICommandThrowing` を経由してこのコマンドにマッピングされます。

## 呼び出し元
- Erq スクリプト／CLI での `load table` ステートメント。

## 主な役割
- まだ存在しない場合にテーブルを作成し、CSV や NDJSON、Raw ブロック、URL、SQL 式など多様な入力ソースからデータを挿入する。
- オプションに応じてヘッダー行の解釈、エンコーディング変換 (`iconv-lite`)、列数の調整や自動型推測などを行う。
- 実行状況（`create table ...` / `insert into ...` / 所要時間と行数）を標準エラーに出力する。
- 処理はトランザクション化され、途中でエラーが発生した場合はロールバックされる。

詳細なオプションと挙動については `load table` ステートメント仕様（このディレクトリ内のドキュメント）を参照してください。
