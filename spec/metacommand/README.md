# メタコマンドの分類

Erq ではメタコマンドを 2 つの層で扱います。

## ドットメタコマンド
- 対話プロンプトで `.` に続けて入力するコマンド。
- ユーザーが直接呼び出し、`src/child.js` の `runCLICommandThrowing` で一対一に処理されます。
- ドキュメント:  
  - [`.help`](./help.md) — ドットメタコマンド一覧や詳細表示  
  - [`.load`](./load.md) — SQLite 拡張をロード  
  - [`.cd`](./cd.md) — 子プロセスのカレントディレクトリ変更  
  - [`.format`](./format.md) — 既定出力フォーマット切り替え
  - [`.debug`](./debug.md) — デバッグログ設定の参照と更新

## 内部メタコマンド
- `load table ...;;` や `set format ...;;` といった言語構文が、実行段階で内部的に発火させるコマンド群。
- ドットメタコマンドとしては公開されておらず、ユーザーが直接入力することはありません。
- ドキュメントは [`internal/`](./internal) 以下に配置しています。
