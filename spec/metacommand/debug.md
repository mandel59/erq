# .debug メタコマンド

## 概要
`.debug` は実行中のセッションで出力するデバッグログのカテゴリを切り替えるドットメタコマンドです。環境変数 `ERQ_DEBUG` と同じ書式でカテゴリを指定でき、変更は親プロセス・子プロセスの双方に即座に適用されます。

## 構文
```text
.debug
.debug on
.debug off
.debug CATEGORY [CATEGORY ...]
```

- 引数なし: 現在のデバッグ設定を表示します。
- `on` / `all` / `true` / `1` など: すべてのデバッグログを有効にします。
- `off` / `none` / `false` / `0` など: デバッグログをすべて無効化します。
- `CATEGORY`: スペースまたはカンマ区切りでカテゴリを列挙します（大文字小文字は無視されます）。例: `.debug sql stack`

指定可能なカテゴリ（例）:

- `sql` — スクリプト実行時に生成される SQL
- `script` — ループ条件などスクリプト専用の補助 SQL
- `import` — 外部データ取り込み時の SQL
- `lifecycle` — 親子プロセスのライフサイクル情報
- `ipc` — IPC メッセージや補完結果
- `stack` — 捕捉した例外のスタックトレース
- `preprocess` — ERQ 内部での補完や解決状況
- `general` — 従来のデバッグ出力全般

## 挙動
- `.debug` は子プロセスの `process.env.ERQ_DEBUG` を更新し、`resolve debug` 値は即座に `setDebugLogging` に適用されます。
- 対応するステートメントは、親プロセス側でも反映されるため、以降の CLI 操作や補完ロジックにも同じ設定が適用されます。
- 引数が空の場合は設定の一覧と使用方法を表示します。空文字列のみを指定すると usage が表示され、設定は変更されません。
