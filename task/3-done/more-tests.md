# 課題: テスト方法の充実

現在はパーサーのテスト、正常系の簡単なテストしか行われていない。

異常系も含めてテストできるようにしたい。

どうすればいいか、計画を立てて実施する。

## 計画
- 現状のテストスイートを棚卸しし、パーサ以外でカバーされていない領域（CLI 異常系など）を特定する。
- CLI をサブプロセスとして実行して終了コードと標準エラー出力を検証できるハーネスを用意する。
- 代表的な異常系（存在しないテーブル参照、メタコマンド誤使用、構文エラー）をケース化して自動テストに落とし込む。
- `npm run test:unit` で新テストを含めたスイートを実行し、グリーンになることを確認する。

## 実施結果
- `tests/cli-error.test.js` を追加し、CLI を子プロセスで動かして挙動を検証する仕組みを導入した。
- 存在しないテーブル参照、`.format` への無効値、構文エラーの 3 ケースをテスト化し、エラーメッセージと終了コードを確認できるようにした。
- 追加後に `npm run test:unit` を実行し、全テストが成功することを確認した。
