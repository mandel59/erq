# 課題: SQL出力をデバッグに移行

Erqスクリプトの実行時に表示されているSQLの表示をデバッグログに移す。

# 課題: デバッグログ機能を使いやすくする

ERQ_DEBUG を拡張し、表示するデバッグ項目を個別に指定できるようにしたい。

- [x] 現在の実装のデバッグログ表示方法の調査。
- [x] 適切なデバッグログ出力方法（フレームワーク等）の選定。
- [x] 選定したデバッグログ出力方法に実装を移行。
- [x] 実際に実行してテストする。`npm run test:unit`

## 修正内容
- 共通のデバッグユーティリティ (`src/debug.js`) を導入し、カテゴリ単位でログ制御できるようにした。
- 既存の SQL/スクリプト系の標準出力をカテゴリ付きの `debugLog` 呼び出しへ移行した。
- `.debug` ドットメタコマンドを追加し、対話中に `ERQ_DEBUG` を参照・変更できるようにした。
- README とメタコマンド仕様を更新し、新挙動をドキュメント化した。
- 単体テストにデバッグ設定まわりのケースを追加し、`npm run test:unit` を完走して確認した。
