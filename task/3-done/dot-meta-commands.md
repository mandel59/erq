# 課題: ドットメタコマンドの使い勝手の改善

ドットメタコマンドの使い勝手を改善する。

- .help メタコマンドを用意して、メタコマンド一覧や、各メタコマンドの使い方を調べられるようにする。
-  オートコンプリーションでメタコマンドと引数を補完できるようにする。

## 実施項目
1. `.help` メタコマンドの追加方針と表示仕様の整理。
2. ドットメタコマンドの補完強化（コマンド名と代表的な引数）。
3. 実装とドキュメント更新、リグレッションテストの追加実行。

## 実施結果
- `src/meta-commands.js` にメタコマンドのメタデータを集約し、`.help` で一覧と詳細を表示できるようにした。
- `src/completer.js` を拡張し、`.help`/`.debug`/`.format` の引数補完や `.cd`/`.load` のパス補完を追加した。
- `tests/cli-error.test.js` に `.help` の正常系・異常系テストを追加し、`tests/completer-meta.test.js` で補完機能を検証するテストを実装した。
- README とメタコマンド仕様書を更新し、`npm run test:unit` を実行して一連の変更を確認した。
