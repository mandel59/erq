# 課題: オートコンプリーターの挙動を改善する

^table 記法のオートコンプリーションを改善する。

現状、 ^ の直後にはスキーマ名かテーブル名しか来ない。

スキーマ名・テーブル名だけ候補にするように修正する。

---

## 実装メモ

- `src/completer.js` の CLI オートコンプリーターで、補完対象トークン直前が `^` の場合は `caretContext` フラグを立てるようにした。
- `caretContext` ではカラム名補完ブロックを完全に飛ばし、代わりにスキーマ名／テーブル名（裸と `schema.table` の両方）の候補のみを組み立てて返すようにした。
- これにより `^table` 構文の途中で Tab を押しても関係ないキーワードや関数が候補に混ざらなくなった。
