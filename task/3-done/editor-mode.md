# 課題: .editor ドットコマンドの追加

Node.js のREPLと同様に機能する、 .editor ドットコマンドを追加する。

.editor コマンドを実行すると、エディターモードに入る。

エディターモードに入っている間は、プロンプトを表示せず、入力したスクリプトをそのまま記録していく。
最後にCtrl+Dを入力することで、入力を完了し、入力されたスクリプトが評価される。
かわりにCtrl+Cを入力すると、入力はキャンセルされ、スクリプトは実行されない。

スクリプトの評価後・入力のキャンセル後は、エディターモードは終了し、もとのプロンプトが表示される。

入力がTTYでない場合、.editorコマンドの実行はエラーになる。
