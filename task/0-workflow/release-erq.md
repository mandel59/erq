# 課題: Erqのリリース作業

1. 3-done にあるタスク文書をもとに、CHANGELOG.md を編集し、リリースの準備をする。
2. CHANGELOG.md への反映が完了した 3-done にある文書を削除する。
3. CHANGELOGと3-doneの更新をコミットする。
4. package.jsonのバージョン番号を更新する。セマンティックバージョニングに従う。バージョンの例: 0.3.1-rc.2, 0.4.0
5. npm run test を実施する。失敗した場合は作業中断。
6. 変更のコミットを行う。Jujutsu VCSが有効の場合はjjコマンドを使う。
7. バージョン番号をもとに、リリース用のタグをgit tagで追加する。タグの例: v0.3.1-rc.2, v0.4.0
8. タグをGitHubにプッシュする。
